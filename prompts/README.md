# Como usar os prompts

Cole no Codex o texto do bloco do arquivo da entrega atual, depois de abrir a raiz.
Não execute todos em sequência automática. T00 exige aprovação da arquitetura; tarefas
posteriores executam o trabalho reversível autorizado sem interromper a cada arquivo.
Uma conversa por resultado, continuação no mesmo chat para corrigir a mesma tarefa.

Use o prompt de revisão ao finalizar, o de falha quando um teste quebrar e o de retomada
após pausa. Perfis de agentes são opcionais: revisão sequencial é fallback suportado.
Não cole segredos, respostas reais de alunos ou o ZIP inteiro nos prompts.
